- Новое: Настройки -> Язык: весь интерфейс на 11 языках или на языке системы
- Новое окно обновления внутри приложения: что нового на вашем языке, индикатор загрузки, а вкладки снова открываются после установки
- Модель теперь умеет перетаскивать нативные элементы, например менять порядок списков или каналов Discord, что раньше зависало в Windows
- Новый параметр «Не приостанавливать, даже если окно перекрыто» в Настройках (и keep_active для модели): страница продолжает реагировать на клики, когда окно за другими
- Модель получает предупреждение, когда страница скрыта, и понимает, когда включить этот параметр
