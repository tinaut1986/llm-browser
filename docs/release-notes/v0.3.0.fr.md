- Nouveau Paramètres -> Langue : toute l'interface en 11 langues, ou dans celle de votre système
- Nouvelle fenêtre de mise à jour dans l'application : les nouveautés dans votre langue, une barre de progression du téléchargement, et vos onglets se rouvrent après l'installation
- Le modèle peut désormais glisser-déposer des éléments natifs, comme réorganiser des listes ou des salons Discord, ce qui restait bloqué sous Windows
- Nouveau « Rester actif même si la fenêtre est masquée » dans Paramètres (et keep_active pour le modèle) : la page continue de répondre aux clics quand la fenêtre est derrière d'autres
- Le modèle est prévenu quand la page est masquée, pour savoir quand activer ce réglage
